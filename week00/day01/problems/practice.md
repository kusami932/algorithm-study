

# 실습 문제: 통합 입출력 검증 프로그램

## 문제 이름: 배열 통계와 알파벳 빈도수

## 문제 설명

정수 'N'과 길이 'N'의 정수 배열이 주어진다
배열의 다음 정보를 구한다
	- 모든 원소의 합
	- 최솟값
	- 최댓값

그 다음 영문 소문자로만 이루어진 문자열 'S'가 주어진다
문자열에 등장한 각 문자의 개수를 알파벳 순서로 출력한다.
	등장하지 않은 문자는 출력하지 않는다

---
## 입력 형식
```text
N
A1 A2 .... AN
S

조건:
1 ≤ N ≤ 100,000
-1,000,000 ≤ Ai ≤ 1,000,000
1 ≤ |S| ≤ 100,000
S는 영문 소문자로만 이루어진다.

## 출력 형식
	첫 번째 줄: 배열의 합 / 최솟값 / 최댓값
	두 번째 줄 ~: 문자 횟수
	
5
3 -2 7 7 0
