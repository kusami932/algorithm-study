풀이 설계
	1. 배열 입력: 길이가 N인 배열을 만든다
	2. 합 계산: 누적 변수 total을 0으로 시작한다
		• 배열의 원소를 한 번씩 확인하므로 시간복잡도는 O(n)
	3. 최솟값과 최댓값 초기화
		** 0으로 초기화하면 안됨 (모든 숫자가 양수/음수일 때 잘못된 결과)
		** 항상 첫 번째 원소 array[0]
	4. 빈도수 배열
		• 문자를 인덱스로 변환 (ch - 'a')
			frequency[0] = 'a'의 개수, frequency[1] = 'b'의 개수


1. long long을 사용한 이유
	N = 100,000 / 각 원소 = 1,000,000
	배열의 합: 100,000 × 1,000,000 = 100,000,000,000
		ㄴ> 이는 일반적인 32비트 int 범위를 넘어선다.
			=> 따라서 합은 long long으로 저장한다.
			
2. array<int, 26> frequency{};
	{}를 사용하면 모든 원소가 0으로 초기화됨 [0, 0, ... 0]
	- 초기화를 빼면 각 원소에 어떤 값이 들어 있는지 보장되지 않을 수 있으므로 반드시 초기화
	
3. 시간복잡도
	배열 길이가 N, 문자열 길이가 M일 때:
		배열 입력: O(n)
		합·최솟값·최댓값 계산: O(n)
		문자열 빈도수 계산: O(m)
		26개 알파벳 출력: O(26) = O(1)
		
		전체: O (n + m)
		
4. 공간복잡도
	배열 저장: O(n)
	빈도수 배열: O(26) = O(1)
	전체: O(n)
	
	배열을 저장하지 않고 입력받는 동시에 합-최대-최소를 계산하면
	O(1) 추가 공간으로도 가능함
		- "길이 N의 배열을 입력받는다"는 연습을 위해 vector에 저장
